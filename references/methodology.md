# 姜胡说 · 内容方法论

> 基于 **431 条**视频的结构拆解、**432 条**开场钩子、**392 条**类比素材（共 1084 条）统计得出。
> 所有段长占比均有视频行号可考；`[视频ID, X.X万赞]` 可用于回原片核对。

**输入**：（本地语料分片） + `structure_2.md`（431 条结构拆解）、（本地语料分片）（432 条开场钩子）、（本地语料分片）（392 条的类比/故事清单，共 1084 条素材，其中明确标"可复用"1045 条）。

**样本基线**：时长中位数 6.2 分钟（均值 7.4）。分布：4–7 分钟 162 条、7–12 分钟 132 条、2–4 分钟 63 条、≥12 分钟 50 条、<2 分钟 26 条。→ **默认值应当按 6 分钟左右写，长片是刻意行为不是基本盘。**

## 一、结构模板

### 0. 贯穿所有模板的一条总纲

他 90% 的口播都在做同一件事：**把"结论"当起点，把"动手动作"当终点**。因此：

- 第一段一定是结论 / 承诺 / 断言（不做背景铺垫）；
- 最后一段一定是行动指令、回扣句或金句；
- 中间所有段落在解决同一个问题——**"你为什么还没有做"**（拆借口、拆门槛、拆质疑）。

在 431 条结构描述里，"收尾"出现 250 次、"复述/总结/回扣"合计约 99 次、"拆"出现 70 次、"反驳/回应/质疑/自证"合计约 65 次——**收尾与"拆障"是他结构的两个硬零件**。

---

### 模板 A：断言—拆障—给法—回扣（"结论前置型"，约占样本一半）

```
断言/承诺（1–5%）
→ 自曝可信度或点名人群（5–10%）
→ 拆掉 1–3 个"我不行"的借口（15–25%）
→ 给出可执行方法 / 步骤（30–45%）
→ 回扣开场那句 + 行动令收尾（5–10%）
```

**各段干什么**

| 段 | 作用 | 写作要求 |
|---|---|---|
| 断言段 | 把结论说死，制造"反常识 + 确定性" | 一句话，不加"今天我们来聊聊"这类礼貌性前缀 |
| 拆障段 | 把观众心里已经存在的反对意见逐个拿走 | 必须点出具体借口原话（"我不会""我没时间""教我赚钱的都是骗子"），再一对一拆 |
| 给法段 | 步骤 / 公式 / 清单，给出"今天就能做的那一步" | 至少一个动作门槛低到荒谬（写两个字也算、十分钟版本） |
| 回扣段 | 复述 + 金句 + 固定用词 | 「试试看。」「散会。」「新年快乐。」「帅就完了。」 |

**实例**

- `7486844955646774565`（49.0万赞，4.1分钟）：承诺（一小时改变一生）→ 给底层公式（技能对别人有用＝另类的 PMF）→ 拆两个借口（"我没技能"→不会可以学；"我没时间"→用手机使用数据反驳）→ 操作法（每天一小时，一半学习一半创造）→ 坚持一年的承诺收尾。
- `7480931979001711881`（9.0万赞，5.3分钟）：抛结论「你不需要什么成本就可以创业」→ 先破"创业尽头是负债"这个 bug → 开车/做饭类比 → 直接回怼骂他的留言 → 讲众筹模式 → 两个案例 → 给出"卡 bug"方法 → 收尾。
- `7637536206296747315`（6.5万赞，9.3分钟）：承诺"每天工作两个小时就能财务自由"→ 声明"不打草稿、想到什么说什么"→ 逐段还原自己的一天 → 回答"为什么两小时能财务自由"→ 给上班族降级版（每天 30 分钟）→ 收尾。

**适配主题**：赚钱方法、方法论、认知纠偏、任何"你要做的其实比你想的简单"的选题。
**风险**：拆障段写太长会变成骂人合集，靠给法段的密度拉回；拆障不足则整条退化成鸡汤。

### 模板 B：数字清单（N 件事 / N 步 / N 种来源，约占 1/4）

```
先报数量（就三件事 / 五步 / 四种来源 / 两个半）
→ 逐条展开，每条 = 讲机制 + 配一个真实真人案例
→ 全部条目复述一遍（recap）
→ 金句或固定用词收尾
```

**关键特征**：先报数、后展开、结尾再复述一遍。清单型几乎必有 recap 段（结构描述里"三步"出现 88 次、"三件事"出现 40 次、"复述"31 次）。

**段长实测（有 L 行号可考的样本）**

- `7551062641335209257`（4.9万赞，8.3分钟，忙一年=0）：强承诺 1% ／ 描述现状 2% ／ 先给三步名词 4% ／ **逐条解释 25%** ／ **回应质疑 16%** ／ **讲素材来源 30%** ／ 完整重述 11% ／ 金句收尾 2%。
  → 结论：**清单只是骨架，一半以上的篇幅是"再补一个可复用案例"和"回应质疑"。**照着写时不要把 3 条平均分配。
- `7575507151829994752`（6.4万赞，11.7分钟，化茧成蝶）：开场+总框架 11% ／ 第一关结茧 15% ／ **第二关液化 49%** ／ 第三关蝶变 8% ／ 关后陷阱+回扣 13% ／ 一句总结 2%。
  → 结论：**中间那一关吃掉一半篇幅**，首尾两关只做骨架。

**实例**：`7642363455722229042`（30.2万赞，2.6分钟，普通人就做三件事）；`7566646562168818971`（3.3万赞，3.6分钟，一人公司五步）；`7590403619493629190`（8.1万赞，12.7分钟，三个方法全部来自线下年会真实案例）；`7672384093882961152`（2.2万赞，8.0分钟，五个问题→把五条正过来串成一套打法）。

**适配主题**：行动清单、赚钱方式枚举、习惯清单、平台规则清单、书单。
**风险**：超过 5 条又没案例会退化成口播版 PPT；他的解法是每条至少配一个"真人样本"。

### 模板 C：案例先行（老伙计/自己的真实案例 → 提炼规则 → 给工具）

```
先用一个真实案例开场（老伙计、社群成员、读者留言）
→ 说明为什么用这种案例（"贴近我们老百姓"）
→ 从案例里提炼出一条规则/一个公式
→ 给一个可直接操作的工具（一张纸、一段提示词、一份清单）
→ 收尾
```

**实例**

- `7514323799211756863`（16.0万赞，9.4分钟）：老伙计把国外白噪音打包挂网、没做推广用户自己来 → 说明为什么用这种案例 → 给工具"一张白纸对折"（左栏写不爽的事，写十条、写不出写一百条、不许批判）→ 举例（Uber／Airbnb／布兰森）→ 成本标准（请客吃饭的钱）→ 目标换成"失败一百次"→ 收尾。
- `7654974450093362486`（0.75万赞，13.2分钟）：两个亲历案例（线下分享→在线专栏，一年 8000 多人、近 100 万，几乎零成本；整理知识库→做 AI 问答），全程"完整复盘、不追求语言流畅"。
- `7517285713059138879`（14.4万赞，9.9分钟）：先讲"怎么学"（北大旁听时朋友半年找到工作、自己"没人要"的经历反证"我不是笨，是方法错"）→ 得出"做真项目才学得会"→ 再讲"怎么赚"→ 给行动令 → 处理质疑（"你就是想卖课"）→ 收尾。

**适配主题**：赚钱方法、需求发现、创业、任何"别人已经做到了"的选题（"结构描述里"案例"出现 91 次，是他第三高频的段落零件）。
**风险**：案例太多会变成故事集。他自己被评论批评过"视频太散、知识点太多"，并在 `7684299809779420425`（1.3万赞）里当场承认"你们不要学我"——**案例必须每次回到同一条规则上**。

### 模板 D：自传式叙事（起点—转折—提炼—行动令）

```
抛结论 → 自曝落魄/起点（中专、没饭吃、被拒、扫街陌拜、在卷闸门上睡着）
→ 讲一个具体的转折动作（一次被看见、一次被逼接活）
→ 提炼成一条可复制的原则
→ 行动令 + 时间承诺收尾（"半年后来感谢我""一年后来我直播间刷礼物"）
```

**实例**

- `7675375380760431882`（1.6万赞，7.1分钟）：承诺方法普适 → 西安没饭吃、中暑靠在卷闸门上睡着的亲历 → 网吧重启就丢代码只能发论坛 → 无人问津仍每天写一年多 → 第一个机会（讲课邀请）→ 机会滚雪球 → 提炼"让别人看见＋积累与专注" → 三件事建议。
- `7346562207859330344`（6.0万赞，5.2分钟，看见）：自曝中专生、敲门做广告、吃不上饭 → 抛洞见 → 毕加索 vs 梵高 → 自述两次被看见的经历 → 回扣"现在是非常好的时代，发出来就有人看到"。
- `7397776555751066914`（4.7万赞，5.8分钟）：先用"改变你的一生""命运的齿轮开始旋转"下强承诺 → **明确预告三段式（别人的故事→我的故事→你的故事）** → 依次展开：奈飞寄 CD／爱彼迎拍一张照片 → 自己第一个商业项目／抖音第一条拿手机怼脸拍 → 你：打扫先扫一个角落、写作马上关掉视频。

**适配主题**：愿景类、身份转变类、需要建立信任的选题（早期占比高，粉丝量起来后明显下降——近期样本多为"案例先行"和"清单"）。
**风险**：成败全在细节的真实性，靠"自曝代价"撑可信度（在卷闸门上睡着、第一次演讲浑身湿透、网吧丢代码）。

### 模板 E：反常识纠错（否定前置 → 指认病因 → 给正确顺序）

```
直接否定主流做法（"你们的方法是错的"）
→ 指出错在哪、代价是什么
→ 给出正确顺序/正确对象（通常是"把顺序倒过来"）
→ 重申收尾
```

**实例**

- `7656465774810369299`（1.34万赞，1.7分钟）：断言大多数人方法错了 → 正确顺序是先想"拍给谁、解决什么问题、带来什么价值"，再想"怎么讲他愿意听" → 反例：为拍而拍＝垃圾里挑好东西。
- `7677980980585581851`（0.6万赞，7.5分钟）：否定受众做法（没商业闭环只会是炮灰）→ 分发／渠道／产品三个关键点 → 四维自检 → 收尾"让用户主动找你"。
- `7620452140850384179`（3.3万赞，5.0分钟，伤疤起号法）：先否定主流方法论并描述照做后的下场 → 论证技巧为何没用（可复制→AI 复制更好→赛道拥挤→潮水退了在裸泳）→ 给正命题 → 三步流程 → 回应"我没有经历"。
- `7655721991399296291`（3.8万赞，7.9分钟）：先否定一句流行口号"做难而正确的事"，给出替代主张"简单的事才有复利"。

**适配主题**：行业误区、方法纠偏、平台规则解读。
**风险**：纯否定没有"正确解"会变成抱怨。他的固定配平是**否定 + 立刻给一个能马上做的小动作**。

### 模板 F：系统/框架长片（分层讲解，≥12 分钟，50 条样本）

```
承诺"一套完整的框架" + 讲法声明（想到哪说到哪／不打草稿／可能删／不是很难是跨代了）
→ 先抛出总结构（三部分／六层／五个环节）
→ 逐块深讲（占比过半）
→ 每块结束小结，整篇复述
→ 一句话或一张图收尾
```

**段长实测**

- `7622329208672406834`（3.4万赞，19.9分钟，短视频内容创作系统）：承诺+讲法声明 5% ／ 抛出三部分 3% ／ 第一部分及时止损 15% ／ **第二部分构建系统 52%** ／ 第三部分闭环 7% ／ 庄家/彩票类比 1% ／ 逐段总结 14%。
- `7683174014608477466`（0.40万赞，29.5分钟，我的短视频系统）：总览五段 SOP（定位／选题／生产／检验／变现）→ 逐段 → 心法层抽讲 → 画图收尾。
- `7574072740934274344`（1.5万赞，20.7分钟，打造赚钱系统）：零层到第五层 → 六层汇总＋成功公式 → 结束语。

**适配主题**：只有他敢做的"整套系统"类选题（短视频系统、AI 知识库、认知系统、赚钱系统）。
**风险**：**流量显著偏低**（同批 0.4–3.4 万赞，而短结论前置普遍 6–30 万赞）。他在 `7622329208672406834` 里明确承认"这样牺牲了流量"、在 `7599692364495572287`（0.38万赞，22.8分钟）宣布以后做"不设计开头和钩子的聊天局"。→ 这是**有意的取舍**，写稿时要清楚：长片靠搜索长尾，不靠推荐。

### 模板 G：演示型（现场做给你看）

```
声明"我现场演示／一镜到底／想到啥说啥"
→ 边做边讲（真实地卡壳、当场承认说错、回看）
→ 产出物（一条视频／一张卡片／一篇文章）
→ 落到观众的动作
```

**实例**：`7607072666188631305`（2.06万赞，7.6分钟，现场演示拍摄与积累）；`7644216083330714886`（1.0万赞，15.1分钟，否掉"在书上画线"→ 现场用 AI 拆解自己书的章节，输出"核心观点／直接关联／可执行方案"三件套 → 当场接进系统）；`7631959846937464070`（0.69万赞，19.1分钟，现场演示灵感池→对撞→复盘→系统升级，其中还演示了"被 AI 回绝"）。

**适配主题**：AI 用法、笔记/知识库、写作与拍摄流程。
**风险**：对内容密度要求最高，容易变成"看我操作"。他的做法是每演示一步补一句"这一步解决了你哪个问题"。

### 模板 H：对谈/嘉宾剪辑（非口播本体）

`7639005685547568399`、`7660018057145748746`、`7442699377501654326`、`7532853093449387283` 等。结构由提问推进，他固定会问三类问题：**第一桶金怎么来 / 遇到的最大困难 / 优秀的人身上有什么**；中段是嘉宾第一人称故事，叙事模板统一为"低谷—试错—复盘—突破"。

- 适配主题：真实案例背书、社群标杆展示（年会案例、老伙计逆袭）。
- 风险：他自己承认这类要额外压缩（`7440077075563760959` 声明"把 20 多个小时压到一个小时之内"），且部分为口语对谈，ASR 错误率高。

### 跨模板的四个固定零件（写稿时必装）

1. **时长/免责声明**（超 7 分钟几乎必有）：「这条视频会很长」「我没打草稿，想到哪说到哪」「我随时可能删了做成收费的」`[7517285713059138879, 14.4万赞]`。
2. **反向筛选**：只讲给"江湖说的老伙计"，用身份标签筛人——既降低杠精比例，也强化社群归属 `[6914665561863621896, 27.6万赞]`。
3. **中段插"回应质疑"**：把评论区的反驳摆到台面上当场处理（"教我赚钱的都是想赚我钱"／"你有百万粉丝我们只有一千"）。样本里"反驳"26 条、"回应"17 条、"自证"12 条。
4. **收尾三段式**：复述要点 + 一句金句/回扣 + 一个固定用词（「试试看。」「散会。」「新年快乐。」「帅就完了。」）。

## 二、钩子类型

432 条开场钩子的类型分布：**结论前置 163 条（38%）**、**强承诺 79 条（18%）**、数字清单 42 条（10%）、反向筛选 39 条（9%）、故事切入 37 条（9%）、其他（含免责、自嘲、场景、悬念、权威引用等）46 条。

### ① 结论前置 / 反常识断言（38%，绝对主力）

- 「这个世界是可以作弊的而且正大光明的作弊这条视频的内容会很长」`[7401507931113475363, 113.7万赞]`
- 「赚钱这个事和工作的努力程度没什么关系蚂蚁也很努力蜜蜂也很努力」`[7424897977501732115, 6.4万赞]`
- 「千万不要太自律啊 自律这个就是个假象」`[7542519534188645683, 1.3万赞]`

**适用场景**：任何有明确观点、能一口气把主张说清的选题。**要把结论当第一句，不做背景铺垫**；反常识强度直接决定前 3 秒留存。
**失败风险**：断言太强而正文不兑现 → 标题党；他自己的判断是「反常识不是找出来的，是站位不同」`[7685771039799889204, 2246赞]`，即反常识必须来自真实立场，不能硬造。

### ② 强承诺（18%）

- 「一个小时就可以改变你的一生我不是在开玩笑我是非常认真的和大家分享这句话」`[7486844955646774565, 49.0万赞]`
- 「听我的做以下三件事用不了半年几个月吧你就会来感谢我」`[7550692629248216359, 7.5万赞]`
- 「每天工作两个小时就能财务自由这个不是危言耸听我过去十年差不多就是这么做的」`[7637536206296747315, 6.5万赞]`

**适用场景**：方法类、清单类；公式是「时间刻度 + 具体结果 + 自我背书」。

### 3.4 使用规则（写口播稿时的三条硬约束）

1. **一个类比只服务一个动作**。他的规则是讲完类比立刻回到操作，从不在类比上多停留、不做文学修饰。典型句式：「打球的方法是什么？是先上场」→ 紧接着就是"先下两个工具，不要研究哪个好"`[7660888653740166415, 30.4万赞]`。
2. **类比主要用来"降门槛"，不是用来"显学问"**。高频出现的位置是：把抽象方法换成身体动作（穿个鞋下楼、拍一张照片、写两个字）、把成本换成生活量级（请客吃饭的钱、一部手机、几毛钱电费）。
3. **只取清单里标"可复用"的素材**。1084 条里有 7 条被明确标为"不可复用"，原因是三类：语料残缺/转写错误、人名与数据无法核实、涉及灰色经历或他人隐私。写稿时要避开这三类，不要为了生动去用无法核实的案例。

- **若主题是清单/行动**：走模板 B，条目控制在 3–4 条，每条配一个真人样本，结尾必须 recap。
- **若主题需要信任**：走模板 C/D，开头用一个真实的人（老伙计/自己）的处境，50–60 秒内完成"处境→代价→承诺"。
- **若主题是纠偏**：走模板 E，否定 + 立刻给一个能马上做的小动作。
- **若主题是"整套系统"**：走模板 F，接受低推荐流量，按搜索长尾设计（用大白话的关键词做小标题）。
- **必装零件**：开头 <20 字内给结论；中段至少处理 1 个真实反对意见；结尾复述 + 金句 + 固定用词。
