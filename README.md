# 姜胡说 · Skill

> 把抖音上那个讲"普通人怎么赚钱、怎么学习、怎么做内容"的姜胡说，蒸馏成一个能替你**找选题、写口播稿、做自媒体**的 skill。

**语料**：433 条抖音口播逐字稿（94.7 万字）+《价值心法》全书
**方法**：多维度提炼 + 三重验证 + 独立 agent 保真度评分
**框架**：借鉴 [女娲 · Skill 造人术](https://github.com/alchaincyf/nuwa-skill)（MIT），并做了以下扩展 ⬇️

---

## 一、它能做什么

和其他"人物 skill"最大的不同：**它不只是会以姜胡说的口吻回答问题，它还能替你干活。**

### 模式一：问答

> **你**：我总是学完就忘，怎么办？
>
> **姜胡说视角**：先别急着找记忆方法。你问一个问题——你上次学完之后，给别人讲过吗？没讲过就不算学过……

### 模式二：创作（本 skill 的重点）

| 你说 | 它给你 |
|---|---|
| 「帮我找 5 个适合我的选题」 | 按他的选题逻辑（反常识 / 痛点 / 认知差 / 亲身实验）给出的具体选题 + 每个选题的钩子设计 |
| 「我想讲『为什么不要辞职做自媒体』，写个口播稿」 | 按他的五段结构（钩子 → 来源锚定 → 主体 → 类比降门槛 → 金句收尾）写出的完整口播稿 |
| 「这条稿子按他的风格改一下」 | 逐句改造：句式、节奏、口头禅、人称比例，并说明改了哪里、为什么 |
| 「这个开头能不能抓住人」 | 用他的四类钩子标准 + 爆款数据做诊断 |

### 模式三：诊断

把作品数据（标题/时长/点赞/完播）丢给它，按他的内容方法论给改进建议。

## 二、与已有实现相比，多了什么

写清楚这一点很重要——已经有其他人做过姜胡说的 skill，本项目的差异如下：

| 维度 | 已有的 `jiang-hushuo-mind` | 本项目 |
|---|---|---|
| **语料来源** | ⚠️ 二手：飞书直播笔记、知乎专栏《400 多期视频干货总结》、思维导图 | ✅ **一手**：他本人的 433 条口播逐字稿（94.7 万字）+《价值心法》全书 |
| **表达 DNA** | ❌ 无（不讲"怎么说话"） | ✅ 从 433 条口播样本提取：句式、节奏、口头禅、人称比例、开场收尾 |
| **能力范围** | 仅问答／给建议 | ✅ 问答 + **找选题 + 写口播稿 + 改稿 + 数据诊断** |
| **质量验证** | ❌ 无 | ✅ 保真度评分卡（立场一致性／风格辨识度／边缘诚实度／来源透明度／结构完整度，100 分制），由**独立 agent** 评分 |
| **可复现性** | ❌ 笔记来源不明 | ✅ 提取流程完全可复现（用同一作者开源的抖音提取工具，见 `sources/README.md`） |
| **引用可溯源** | ❌ 无金句库 | ✅ 每句引用可定位到具体视频（含日期）或书中章节 |
| **诚实边界** | 3 条泛泛而谈 | ✅ 系统性局限声明 + 内在张力 + 反模式黑名单 |

一句话：**别人蒸馏的是"读到的姜胡说"，我们蒸馏的是"读完了姜胡说全部作品和那本书的姜胡说"。**

### 借鉴了女娲（nuwa-skill）的哪些部分

| 借鉴内容 | 说明 |
|---|---|
| 五层产物结构 | 怎么说话（表达 DNA）／怎么想（心智模型）／怎么判断（决策启发式）／什么不做（反模式）／知道局限（诚实边界） |
| 三重验证 | 跨域复现 + 生成力 + 排他性，用来筛出真正属于他的心智模型 |
| 回答工作流 | Agentic Protocol：遇到需要事实的问题先查再做功课 |
| 保真度评分卡 | 5 维度 100 分，答题与评分分离（避免自评偏差） |
| 反模式黑名单 | 例如"编造此人没说过的话"是头号禁令 |

**我们扩展的部分**：一手语料优先的采集与转写流水线、表达 DNA 的口播样本分析、创作模式（选题/写稿/改稿）、可复现的语料索引。

## 三、安装

### Hermes Agent

```bash
cp -r jianghushuo-skill ~/.hermes/skills/jianghushuo
```

### Claude Code / Codex CLI / Cursor

```bash
cp -r jianghushuo-skill ~/.claude/skills/jianghushuo    # Claude Code
cp -r jianghushuo-skill ~/.codex/skills/jianghushuo     # Codex CLI
cp -r jianghushuo-skill ~/.cursor/skills/jianghushuo    # Cursor
```

### 任何 runtime

把本目录放到对应 runtime 的 `skills/` 下即可，入口是 `SKILL.md`。
