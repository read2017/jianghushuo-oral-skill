# 口播稿模板（姜胡说式）

> 用法：按缺口填。**默认按 6 分钟写**（他的时长中位数是 6.2 分钟，长片是刻意行为不是基本盘）。
> 其他七个结构模板见 [`../references/methodology.md`](../references/methodology.md)。

---

## 模板 A：断言 — 拆障 — 给法 — 回扣（最常用，约占他内容的一半）

```
【① 断言 / 承诺】占 1–5%
  一句把结论摔在桌上，不加"今天我们来聊聊"。
  句式候选：____ 都是错的 ／ 普通人就做 ____ 件事 ／ 千万不要 ____ ／ 我告诉你怎么 ____
  要求：≤20 字，能单独当标题。

【② 自曝可信度 / 点名人群】占 5–10%
  句式候选：我是中专生 ／ 我亏过 ____ ／ 这条是给 ____ 的人看的 ／ 别看我 ____
  要求：挂自己的证据，不许谦虚式自夸。

【③ 拆障】占 15–25%（至少 2 个具体借口，逐个拆）
  借口 1：「____」（要写观众心里真有的那句话）→ 拆：____
  借口 2：「____」→ 拆：____
  ⚠️ 拆障段写太长会变成骂人合集，靠第 ④ 段的密度拉回来。

【④ 给法】占 30–45%
  第一步：____（门槛低到荒谬：写两个字也算 / 十分钟版本）
  第二步：____
  第三步：____
  + 一个真实案例（老伙计 / 自己 / 学员），讲完必须回到同一条规则上。

【⑤ 回扣 + 行动令】占 5–10%
  回扣开场那句：____
  给后果 / 时间账：____（"几个月后你会来感谢我"）
  ⚠️ 不总结、不喊口号、不求关注。
```

## 模板 B：数字清单

```
【报数量】「普通人就做 ____ 件事」/「分享 ____ 句话」（数字要么小到不像话，要么大到夸张）
【逐条展开】每条 = 讲机制 + 配一个真实案例（至少一个案例来自真人，不是虚构）
【复述一遍】把 N 条再报一次（清单型几乎必有 recap）
【收尾】一句金句
⚠️ 超过 5 条又没案例，会退化成口播版 PPT。
```

## 模板 C：案例先行

```
【真实案例开场】（老伙计 / 读者留言 / 自己的经历）
【为什么用这个案例】「贴近我们老百姓」
【提炼一条规则 / 一个公式】
【给一个可直接操作的工具】（一张纸 / 一段话 / 一份清单）
【收尾】
```

## 模板 D：自传式叙事

```
【抛结论】
【自曝起点】（中专 / 没饭吃 / 被拒 / 在卷闸门上睡着——细节要真实到有痛感）
【一个具体的转折动作】（一次被看见 / 一次被逼接活）
【提炼成可复制的原则】
【行动令 + 时间承诺】
```

## 模板 E：反常识纠错

```
【直接否定主流做法】「你们的方法是错的」
【指出错在哪、代价是什么】
【给出正确顺序】（通常是把顺序倒过来）
【立刻给一个能马上做的小动作】← 少了这个就会变成抱怨
```

## 写完必查（十项，逐条打勾）

- [ ] 第 1 句是结论，且能单独当标题
- [ ] 前 3 句出现「你」或「大家」，且合计 ≤40 字
- [ ] 「就」够密（每 100 字 ≥1 次）
- [ ] 报了数字（三件事 / 两小时 / 一年）
- [ ] 有一个降门槛的形容词（简单 / 特别简单 / 没什么成本）
- [ ] 替观众免责了（"不是你的问题" / "不是因为你没能力"）
- [ ] **没有禁用词**：家人们 / 宝子 / 老铁 / 赋能 / 抓手 / 颗粒度 / 护城河 / 组合拳 / 内卷 / 躺平 / 三连 / 关注我 / 感谢大家
- [ ] 有至少一个**可触摸的实物**类比（纸 / 印钞机 / 蚂蚁 / 挖井 / 打地鼠 / 操作系统）
- [ ] 结尾给后果或行动令，不是"总结一下"
- [ ] 有一个**今天就能做**的动作
