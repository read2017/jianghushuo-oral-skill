## 二、提取方法（可复现）

抖音语料的提取**不是手工整理，而是一套可复现工具链的产物**：`douyin-creator-research`（博主级全量研究）与 `douyin-video-transcript`（单条视频口播提取）——**与本 skill 同源、配套发布**（同一作者开源，属于同一个「抖音内容研究」系列）。

也就是说：本 skill 的语料与方法论来源，是那一套抖音提取工具；而本 skill 是在它之上做的**人物蒸馏**。流程为：

1. **作品清单**：翻取创作者主页作品列表接口，取得全量作品元数据（发布时间、点赞、时长、描述、直链）→ 433 条
2. **音频提取**：有独立音频流的取音频流；仅合并档的下载最低清晰度视频后抽音轨
3. **本地转写**：`mlx-whisper` + `whisper-large-v3-turbo`，禁用 initial prompt（实测会诱发专名重复幻觉）
4. **归档**：逐条落盘 transcript + 时间轴 + 元数据

**已知局限**：ASR 转写存在同音错字（如「你没打炒稿」实为「没打草稿」）。因此本 skill 中标注为「原话」的引用，若用于公开发布，建议核对原视频。

## 四、分发边界（重要）

本仓库是**公开发布**的，因此明确区分「能发布什么」与「不能发布什么」：

| | 内容 | 是否随仓库发布 | 理由 |
|---|---|---|---|
| ✅ | 提炼结论、心智模型、方法论、表达风格规则 | 发布 | 本 skill 的原创产出 |
| ✅ | **有限引用**（短句、金句，标注出处与日期） | 发布 | 评论、引用、说明性使用 |
| ✅ | 语料索引（标题/日期/点赞/主题标签） | 发布 | 公开可见的元数据 |
| ❌ | 433 条视频逐字稿全文（94.7 万字；431 条转写可用） | **不发布** | 视频版权归姜胡说，整篇转发超出引用范围 |
| ❌ | 《价值心法》全书 OCR 文本（22 万字） | **不发布** | 图书版权归作者与台海出版社 |

**做法**：全量语料（采集 433 条，其中 431 条可用）只保留在本地分析环境（`06_content_research/creators/jianghushuo/`）。仓库内引用一律删减到必要长度，并标注「出自《视频标题》（日期）/《价值心法》第 N 章」。

如果你的目的是让使用者也能自己判断结论对不对，仓库里提供的是**可复现的提取方法**（见第二节），而不是语料本身。
